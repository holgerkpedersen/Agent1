Alternate chat surface beside the terminal REPL. It runs the same turn pipeline as the REPL, so tools work here: a message can read, run or change files exactly as a terminal turn can. A live REPL in this process shares its conversation. Type / for the REPL command list - all of them, fuzzy-matched, so /mdl finds model. Pick one with the arrow keys and Tab/Enter, and its usage line is filled in for you. | performance dashboard
