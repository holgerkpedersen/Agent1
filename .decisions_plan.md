# Autonomous Decision Improvement Plan

**Card:** `9bc4327f46b34853bb7fac0334c398cb`  
**Title:** Improve Autonomous Decisions in Agent1  
**Date:** 2026-08-15  

## Problem Statement

Agent1 makes autonomous decisions during tool execution, but these decisions are:
1. Not detected or recorded as they happen
2. Not compared against stated decisions in `.decision.json` to flag discrepancies  
3. Not collected into a structured pipeline for improvement
4. Not used to evolve the major decisions that guide the agent

Currently `_record_llm_experience()` captures LLM outcomes but not **which decision** led to an action, nor whether that action matched what the decision prescribed.

## Phase 2: Flag Discrepancies

### 2.1 Discrepancy Detector (`agent_core/discrepancy.py` — NEW)

Create a module to detect when agent actions diverge from stated decisions:

```python
def check_decision_compliance(
    workspace: str | Path,
    tool_name: str,
    args: dict[str, Any],
    result: str,
    affected_files: list[str] | None = None,
) -> list[Discrepancy]:
    """Check whether an action complies with active decisions.

    Returns a list of Discrepancy objects describing mismatches between
    what the decision prescribed and what actually happened.
    
    Example discrepancy:
      - Decision #002: Block writes to agent_core/security/
      - Action: edit_file(path='agent_core/security/allowlist.py', ...)
      - Result: DISCREPANCY — write blocked, but tool was called anyway
    """

@dataclass
class Discrepancy:
    decision_id: str
    decision_title: str
    action_tool: str
    action_args: dict[str, Any]
    discrepancy_type: str  # "blocked_action", "unresolved_context", "contradiction"
    severity: str  # "warning", "error", "critical"
    suggestion: str | None = None
```

## Phase 4: Improve Major Decisions

### 4.1 Improvement Pipeline (`agent_core/decision_improvement.py` — NEW)

Create the logic to analyze collected data and propose updates to `.decision.json`:

```python
def detect_drift(
    workspace: str | Path,
    decision_id: str,
    discrepancies: list[dict[str, Any]],
) -> DriftAnalysis:
    """Analyze whether a decision is being violated repeatedly.
    
    Returns analysis including:
    - Frequency of violations
    - Common patterns in violations
    - Suggested resolution (update, resolve, or investigate root cause)
    """

def propose_decision_updates(
    workspace: str | Path,
    collector: DecisionCollector,
    threshold: float = 0.5,  # Discrepancy ratio to trigger update
) -> list[DecisionUpdateProposal]:
    """Propose updates to decisions based on collected data.
    
    A proposal includes:
    - decision_id: The original decision
    - suggested_changes: What should change in the decision
    - evidence: Supporting discrepancy data
    - confidence: How confident we are in the suggestion (0-1)
    """

@dataclass
class DriftAnalysis:
    decision_id: str
    violation_count: int
    total_actions: int
    violation_rate: float
    common_patterns: list[str]
    recommendation: str  # "update", "resolve", "investigate"

@dataclass  
class DecisionUpdateProposal:
    decision_id: str
    suggested_title: str | None = None
    suggested_decision: str | None = None
    suggested_rationale: str | None = None
    evidence: list[dict[str, Any]]
    confidence: float  # 0.0 to 1.0
```

## Implementation Order

1. **Phase 2 first** — Discrepancy detection is the foundation; everything else depends on it
   - Create `agent_core/discrepancy.py` with `Discrepancy` dataclass and `check_decision_compliance()`
   - Add `.discrepancies.jsonl` storage to `agent_core/decisions.py`
   - Integrate into `_execute_tool_call()` in `agent_core/agent.py`

2. **Phase 1** — Decision detection builds on discrepancy tracking
   - Extend `record_autonomous_decision()` in `agent_core/decisions.py`
   - Instrument tool execution to detect autonomous decisions
   - Update `decisions_as_system_prompt()` to include autonomous context

3. **Phase 3** — Collection aggregates what's been detected and flagged
   - Create `agent_core/decision_collector.py`
   - Hook into `_finish_turn()` for turn-level collection
   - Implement `aggregate_periodic()` for review-ready summaries

4. **Phase 4** — Improvement uses collected data to evolve decisions
   - Create `agent_core/decision_improvement.py`
   - Implement drift detection and proposal generation
   - Add `apply_decision_updates()` to update `.decisions.json`

5. **Phase 5** — CLI commands expose the system to users
   - Add CLI commands in `agent_core/cli/interactive.py`
   - Wire up to agent dashboard if applicable
